# Sistema de Señalética Inteligente para Reciclaje - Campus UAI

### Información del Equipo
- **Integrantes:**
  - Moira Oñate 
  - Javiera Rivera 
  - Antonia Torres 

- **ODS Seleccionado:** ODS 12 - Producción y consumo responsables
- **Problema a resolver:** En las estaciones de contenedores diferenciados del campus UAI (edificio A), el reciclaje llega mezclado: botellas, latas y vidrio se depositan junto con basura y restos de comida. La señalética existente es clara pero está poco visible (bajo la altura de los ojos), y no hay retroalimentación que indique al usuario si clasificó bien.

### Descripción del Proyecto
Sistema de señalética y retroalimentación visual para estaciones de reciclaje, inspirado en el código de colores de un semáforo. Combina un panel visible a la altura de los ojos, un sensor en el contenedor que entrega feedback inmediato (luz verde/roja) al depositar un residuo, y un panel de impacto colectivo que muestra los kilos reciclados y la meta mensual del edificio, buscando reducir la contaminación cruzada de residuos y generar conciencia ambiental en la comunidad UAI.
