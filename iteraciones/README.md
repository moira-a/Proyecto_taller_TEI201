# Iteraciones del Prototipo

## Iteración 1: Montaje inicial

En la primera etapa se realizó el montaje básico del sistema utilizando un Arduino Uno, un sensor inductivo y un LED indicador.

El objetivo fue comprobar que el sensor pudiera detectar la presencia de un objeto metálico y que el Arduino respondiera encendiendo el LED.

## Iteración 2: Incorporación del buzzer

Una vez comprobado el funcionamiento del sensor y del LED, se agregó un buzzer como señal sonora.

Con esta modificación, cuando el sensor detecta un objeto metálico, el sistema entrega dos tipos de retroalimentación:

- Señal visual mediante el LED.
- Señal sonora mediante el buzzer.

## Iteración 3: LED externo en la tapa

Para mejorar la visibilidad del sistema, se incorporó un segundo LED ubicado en la tapa del prototipo.

Este LED se conectó mediante cables para permitir su instalación fuera de la protoboard y se programó para funcionar al mismo tiempo que el LED principal.

## Iteración final

La versión final integra:

- Sensor inductivo.
- Arduino Uno.
- LED principal.
- LED externo en la tapa.
- Buzzer.
- Estructura diseñada en 3D.

Las fotografías y videos del funcionamiento del prototipo se encuentran en la carpeta `pruebas`.
